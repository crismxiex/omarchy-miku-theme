# miku — an Omarchy theme

Dark, teal-tinted stage-at-night theme inspired by Hatsune Miku.
Written for the current Omarchy theme format (`quattro` branch): named color keys plus `mode = "dark"`.

![preview](preview.png)

## Install

    omarchy theme install https://github.com/crismxiex/omarchy-miku-theme.git
    omarchy theme set miku

Or copy this folder to `~/.config/omarchy/themes/miku/` and run `omarchy theme set miku`.

(`omarchy-theme-set miku` does the same.) Cycle wallpapers with `omarchy theme bg next`.

## Files

| File | Purpose |
|---|---|
| colors.toml | The palette. Omarchy templates generate Hyprland, the shell (bar, menu, notifications, lock), terminals, Neovim (aether.nvim), VS Code, Chromium, etc. from it |
| btop.theme | Hand-tuned btop colors (overrides the generated one): teal boxes, deep teal → teal → pink meters |
| icons.theme | Yaru-prussiangreen (teal) icon set |
| keyboard.rgb | Keyboard backlight = accent teal |
| backgrounds/ | Original generated wallpapers (no third-party artwork) |
| preview.png | Theme picker preview |

Wallpapers can be regenerated at any size with `python make-wallpaper.py [out_dir] [width] [height]` (needs Pillow).
